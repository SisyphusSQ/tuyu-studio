# 工作台布局

## 目标与边界

定义桌面工作台的默认信息架构、密度、长文本处理和无落地页要求。本文只约束体验布局和可用性规则，不定义领域对象字段、存储格式或运行时实现。

工作台打开项目后直接进入生产界面，默认是 Project Canvas。任何欢迎页、营销页或说明页都不能挡在项目编辑路径前。

## 输入 / 输出

| 输入 | 输出 |
| --- | --- |
| 项目元信息、保存状态、运行队列摘要 | Top Bar 展示项目、保存、队列、导出、设置入口 |
| 资产、剧本、Blueprint、搜索条件 | Left Rail 展示资产库、剧本列表、模板、历史和拖拽源 |
| Project Canvas 视图模型 | Canvas 展示节点、边、Frame、Blueprint、状态徽标、Agent 来源 |
| 当前选中对象 | Inspector 展示属性、关联、连续性、任务、运行记录、审计 |
| 健康检查、错误、任务事件 | Bottom Bar 展示当前选择、状态摘要和可展开详情 |

所有文件路径在界面中以项目相对路径或脱敏摘要显示，示例统一使用 `{studio_root}`。

## 核心对象或规则

| 区域 | 规则 |
| --- | --- |
| Top Bar | 高度固定；项目名超长时中间省略；保存状态和队列状态不挤压主命令 |
| Left Rail | 支持资产、剧本、Blueprint、搜索、运行历史 tab；列表和缩略图都有稳定尺寸 |
| Canvas | 占据主区域；平移、缩放、选中态不改变节点几何尺寸；网格亮度可调 |
| Inspector | 固定最小宽度；窄屏可折叠为抽屉；切换对象不丢未保存输入 |
| Bottom Bar | 只展示可行动状态；错误和健康项可点击展开 |

密度要求：

- 默认布局面向重复生产，不使用大面积介绍性模块。
- 按钮优先使用图标加 tooltip，关键命令可带短文本。
- 节点、面板、列表都要有最小和最大尺寸，不能因动态内容导致布局跳动。
- 长项目名、长节点标题、长错误摘要使用折行、省略或可复制详情区，不撑破按钮或面板。
- 剧本、提示词、错误详情这类长文本必须使用可滚动、可复制区域。

## 状态推进

| 状态 | 推进规则 |
| --- | --- |
| 项目打开中 | Top Bar 显示只读加载态，Canvas 不接受编辑 |
| 项目已打开 | 进入 Project Canvas，并恢复上次视口、主题、网格亮度和面板尺寸 |
| 有未保存更改 | Top Bar 显示待保存，Inspector 字段保留编辑态 |
| 保存完成 | Top Bar 显示最近保存时间，Bottom Bar 清除已解决错误 |
| 队列运行中 | Top Bar 和 Bottom Bar 同步显示运行数量和可打开入口 |
| 健康异常 | Bottom Bar 显示最高严重级别，并可进入 Health View |

## Canvas-first 五区布局

| 区域 | 内容 | 视觉约束 |
| --- | --- | --- |
| Top Bar | 项目、保存状态、ProviderMode、运行队列、导出、设置 | 高度固定，命令密集但不挤压项目名 |
| Left Rail | 节点模板、Blueprint、资产、剧本、历史、搜索 | 以图标 + 短标签为主，支持折叠窄栏 |
| Project Canvas | 无限画布、节点、边、Frame、运行状态、结果和 Agent 候选 | 主视觉区域，不放营销说明和文档卡片堆 |
| Inspector | 当前选择、属性、上下文、任务、运行、Review、审计 | 选中对象变化快，表单和任务入口稳定 |
| Bottom Bar | zoom、网格、minimap、健康、队列、事件摘要 | 不遮挡画布，点击展开详情 |

## 脚本展开画布工作面

| 元素 | 布局要求 | 交互要求 |
| --- | --- | --- |
| 脚本展开表 | 作为 Project Canvas 上的宽表 Frame 展示，可在暗色和暖浅模式下保持可读 | 支持横向滚动、缩放、全屏展开 |
| 顶部动作条 | 贴合表格上方，包含重新生成、生成分镜、下载 | 每个动作都有 tooltip、状态和审计事件 |
| 视图切换 | 表格右上角提供脚本视图 / Shot 视图 / Prompt 视图 | 切换只改变显示投影，不改变领域数据 |
| 行级内容 | 镜号、时长、画面描述、角色、角色描述、角色图等列尺寸稳定 | 行级确认、重生成、进入 Inspector |
| 角色图缩略图 | 固定比例和尺寸，缺失时显示占位与恢复入口 | 不因图片大小撑高整行 |

## Dark / Warm Light Canvas

| Token | Dark Canvas | Warm Light Canvas |
| --- | --- | --- |
| background | 深色低眩光背景 | 偏暖浅底，避免纯白和高眩光 |
| grid | 点阵网格亮度可调，默认中低对比 | 点阵网格亮度可调，默认柔和 |
| panel | 比背景略高一层，边框低对比 | 白暖面板，边框更明确 |
| text | 主次层级清晰，不靠纯白大面积文本 | 使用深灰层级，不用纯黑大面积压迫 |
| selected | 边框、投影、状态条共同表达 | 边框和轻投影为主，避免高饱和块 |
| active/hover | 不改变几何尺寸 | 不改变几何尺寸 |

## 错误语义

| 错误 | 展示 |
| --- | --- |
| 项目无法打开 | 阻断进入画布，提供恢复、选择其他项目、查看详情 |
| 保存失败 | 不清空表单，字段保留未保存标记，Bottom Bar 给出重试入口 |
| 布局数据损坏 | 使用安全默认布局打开，提示可恢复上次备份 |
| 面板配置不可用 | 回退默认布局，并记录项目健康项 |
| 长文本无法完整展示 | 使用详情面板，不截断原始内容 |

错误提示必须包含下一步动作，不能只显示内部异常。

## 恢复与重试

- 工作台布局配置损坏时，回退默认五区布局，旧配置保留为恢复材料。
- 保存失败时允许重试保存、另存布局快照或继续编辑。
- Inspector 切换时若存在未保存内容，提供保存、丢弃、停留当前对象三个选择。
- 面板尺寸异常时提供“恢复默认布局”命令。
- 队列状态读取失败时，保留编辑能力并提示运行信息暂不可用。

## 验收标准

- 打开项目后默认进入 Project Canvas，不出现挡住生产操作的落地页。
- Top Bar、Left Rail、Canvas、Inspector、Bottom Bar 五区职责清晰且尺寸稳定。
- 脚本展开表格在画布内可读、可全屏、可逐行确认，不会遮挡 Inspector 或 Bottom Bar。
- 长标题、长项目名、长错误、长正文不会撑破节点、按钮或面板。
- 窄屏下左右面板可折叠，核心画布和当前任务可继续操作。
- 保存、运行、健康、错误状态都有一致入口和可行动详情。
