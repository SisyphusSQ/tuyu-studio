# 画布交互

## 目标与边界

定义 Project Canvas 的导入、节点创建、Blueprint、Agent 命令反馈、连线、双层 Frame、搜索、键盘路径和非法操作反馈。本文不定义图数据 schema，也不决定具体渲染库。

## 输入 / 输出

| 输入 | 输出 |
| --- | --- |
| 用户拖入文件或资产 | Asset 记录、可选节点、绑定候选 |
| 双击空白或快捷键 | 节点创建菜单 |
| Blueprint 插入命令 | 一组节点、边、Frame、输入槽和输出契约 |
| Agent Studio Command | 可见画布变更、候选节点或 Agent-visible error |
| 拖出连接线 | 合法关系列表和边创建请求 |
| 框选或多选 | 批量移动、批量操作上下文 |
| 生产组任务命令 | FrameRun 入口、能力预检、历史摘要 |
| 脚本展开命令 | Canvas Table View、Shot 候选行、全屏展开状态 |
| 搜索关键词 | 定位节点、临时高亮关系 |
| 键盘命令 | 选择、移动、撤销、重做、删除确认 |

## 核心对象或规则

拖拽导入：

- 从系统文件区拖入画布时，先进入导入确认，不直接写入正式对象。
- 已在资产库中的文件拖入节点时，优先建立绑定，不重复复制。
- 用户选择的外部文件只作为单次输入来源，正式引用必须复制到项目资产区或记录受控引用。
- 不支持的文件类型要显示原因和允许的替代动作。

节点创建：

- 双击空白、快捷键、新建菜单都打开同一个节点创建面板。
- 创建菜单按 Source、Concept、Continuity、Production、Output、Review、Organizer、Handoff 分组。
- 常用条目至少包含 Script、Character、Scene、Prop、Style、Shot、Prompt、Fusion、Asset、Package、VideoResult、ReviewNote、ReferenceGroup、ProductionFrame。
- Blueprint 可以从左侧入口、空白菜单或 Agent 命令插入；插入前必须展示输入槽和输出契约。
- Shot.status 可进入 `package_ready`，但不能由前端绕过导出校验直接设置。
- PromptRun 只通过任务记录和领域字段引用，不作为 GraphNode 或 GraphEdge 端点。

脚本展开 Table View：

- 用户可从 ScriptNode、ScriptScene、Blueprint 或 Agent 命令生成脚本展开表。
- 表格作为画布上的可展开节点/Frame 呈现，支持平移、缩放、全屏展开和横向滚动。
- 表格列至少包含镜号、时长、画面描述、角色、角色描述、角色图；可按项目需要追加第二角色、道具、场景或提示词摘要。
- 顶部动作至少包含重新生成、生成分镜、下载；动作必须走 Studio Command 并写 Run/Event/Audit。
- 行级操作只能创建候选 Shot 或确认 Shot；不能静默覆盖已确认 ShotCard。
- 全屏展开只改变 UI viewport，不改变 ProjectCanvas truth。

Agent 命令反馈：

- Agent 创建或移动节点时，节点带 `source=agent` 标记和可打开的 command audit。
- Agent 生成的候选节点默认进入 candidate，用户确认后才变成正式上下文。
- Agent 命令失败时不改变画布，错误靠近操作区域显示，并同步进入 Bottom Bar。
- 人类接管 Agent 候选后，后续修改来源变为 human，但保留来源链路。

连线与关系选择：

- 从节点拖出连接线后必须打开关系选择器。
- 关系选择器只显示当前源节点和目标节点之间合法的关系。
- 非法关系不创建临时边；只显示拒绝原因和推荐关系。
- 多关系候选需要显示含义、方向和是否会影响上下文解析。

Frame、历史与搜索：

- 外层 `ProductionFrame` 用于组织可运行生产上下文，包含任务意图、参考组、输出节点、能力要求和历史摘要。
- 内层 `ReferenceGroup` 用于组织输入节点，表达视频动作节奏、角色身份服装、场景参考、文本要求等参考角色。
- 输出节点属于 ProductionFrame，不属于 ReferenceGroup；输出可以是文本、图片、视频或交接包。
- ProductionFrame 移动默认带动参考组和输出节点，但不改变 Shot、Prompt、Asset 等领域关系。
- 历史轨只默认展示当前版本、收藏版本和最近成功版本；失败、取消、草稿通过运行详情查看。
- 缺少图片理解、视频理解或视频生成 capability 时，保留 Frame 与节点，仅禁用、降级或转入手动路径。
- 搜索支持标题、编号、状态、资产名、错误码和标签。
- 搜索定位时保留当前缩放，仅滚动画布到可见区域并临时高亮。

键盘支持：

- Tab 在画布对象和面板之间有确定顺序。
- 方向键可微移选中节点，带修饰键时加大步长。
- Delete 触发删除确认，不直接删除有依赖对象。
- Esc 取消连线、框选、菜单和临时搜索高亮。

## 状态推进

| 状态 | 推进规则 |
| --- | --- |
| 空闲 | 可选择、拖拽、创建、搜索 |
| 拖入中 | 显示可投放区域和导入类型 |
| 导入确认 | 展示文件摘要、目标对象和路径策略 |
| 连线中 | 高亮合法目标，隐藏或弱化非法目标 |
| 关系待选 | 用户选择关系后才提交边创建 |
| Blueprint 候选 | 展示输入槽、输出契约和将创建的节点/边，等待确认 |
| Agent 候选 | Agent 输出候选节点或连线，等待用户接受或拒绝 |
| 脚本展开 | 展示表格候选、可全屏、可生成分镜、可逐行确认 |
| 批量选择 | 批量命令只显示对全部对象合法的动作 |
| 生产组运行预检 | 校验参考输入、输出节点、能力要求和写入目标 |
| 搜索定位 | 高亮结果和相邻关系，退出后恢复视觉状态 |

## 错误语义

| 错误 | 语义 |
| --- | --- |
| unsupported_file_type | 文件类型不支持导入 |
| path_rejected | 路径不满足项目守卫规则 |
| illegal_node_relation | 源节点和目标节点不能建立该关系 |
| blueprint_contract_invalid | Blueprint 输入槽或输出契约不满足当前画布 |
| script_expansion_invalid | 脚本展开表缺少必要列、source range 或行级字段 |
| agent_command_failed | Agent 命令未通过校验或执行失败 |
| dependency_delete_blocked | 删除会破坏仍被引用的对象 |
| frame_action_conflict | Frame 批量动作和内部节点状态冲突 |
| frame_missing_output | 生产组缺少输出节点或写入目标 |
| provider_capability_missing | 当前 provider 不支持任务必需能力 |
| search_no_result | 无匹配节点或资产 |

非法操作反馈必须靠近操作位置出现，并同步进入 Bottom Bar 摘要；安全类拒绝还要写审计事件。

## 恢复与重试

- 导入失败后保留导入面板，允许重新选择文件或改为复制到项目资产区。
- 连线失败后保留源节点和目标节点高亮，允许重新选择关系。
- 批量移动失败时回滚到移动前布局，并提示失败对象。
- 删除被阻断时展示依赖列表，用户可跳转到相关节点处理。
- 生产组缺少媒体理解能力时，允许改为文本描述、手动分镜表或只生成提示词。
- 生产组缺少视频生成能力时，保留视频输出意图，转为导出交接包或等待用户配置生成 provider。
- Agent 候选可接受、修改后接受或拒绝；拒绝不删除其 audit。
- 脚本展开失败时保留 ScriptDocument，允许重新生成、手动拆场或逐行补字段。
- 搜索无结果时保留关键词，允许清除过滤或扩大范围。

## 验收标准

- 用户能通过拖入文件创建资产或绑定节点，并看到路径策略。
- 节点创建入口一致，创建后节点尺寸和标题显示稳定。
- Blueprint 插入能创建完整节点、边、Frame、输入槽和输出契约。
- 脚本展开表能在画布中展开、全屏、横向滚动，并逐行生成或确认 Shot。
- Agent 操作在画布上可见，失败不污染正式画布状态。
- 任意连线都经过关系选择器，非法关系不会写入图。
- ProductionFrame 与 ReferenceGroup 的移动不改变领域关系，移动和搜索都可回退视觉状态。
- 生产组任务入口能展示可运行、可预览、可降级或不可运行原因。
- 历史轨默认只展示当前、收藏和最近成功版本，完整失败详情仍可追溯。
- 画布核心操作有键盘路径，危险操作有确认和审计。
