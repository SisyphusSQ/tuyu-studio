# Inspector 与任务面板

## 目标与边界

定义 Inspector 的 tab 结构、未保存编辑、版本冲突、任务预览、运行历史、审计入口和节点级任务命令。本文不定义任务执行器内部流程。

## 输入 / 输出

| 输入 | 输出 |
| --- | --- |
| 当前选中节点或边 | Inspector Header、状态、主操作 |
| 领域对象字段 | 属性 tab 表单和校验结果 |
| 入边、出边、资产引用 | 关联 tab 列表和跳转 |
| 连续性规则和冲突 | 连续性 tab 警告和修复建议 |
| 可执行任务清单 | 任务 tab 命令、预览和运行请求 |
| PromptRun 记录 | 运行记录 tab 详情 |
| audit/events.jsonl 摘要 | 审计 tab 时间线 |

## 核心对象或规则

Inspector 固定 tab：

| Tab | 规则 |
| --- | --- |
| 属性 | 编辑领域字段；必填、格式、状态转换即时校验 |
| 关联 | 展示入边、出边、引用资产、包、结果和跳转 |
| 连续性 | 展示锁定规则、冲突、警告、修复建议 |
| 任务 | 展示节点可用任务、上下文预览、运行按钮、输出契约 |
| 运行记录 | 展示 PromptRun 列表、输入摘要、输出、错误、重试入口 |
| 审计 | 展示用户操作、状态变更、导出、回收和安全拒绝 |

未保存编辑：

- 字段编辑进入 dirty 状态后，切换节点必须确认。
- 自动保存失败不能清空输入，也不能覆盖用户正在编辑的字段。
- 同一对象在多个面板或窗口中编辑时，以对象 version 检测冲突。

版本冲突：

- 当前 version 落后时，禁止静默覆盖。
- 展示本地编辑、远端已保存字段和冲突字段。
- 用户可以保留本地、新建修订、放弃本地或刷新后重做。

节点级任务命令：

| 当前选择 | 命令 |
| --- | --- |
| ScriptNode | 拆场、生成镜头候选、摘要、检查人物和道具 |
| ShotNode | 优化提示词、生成参考图、连续性检查、导出交接包 |
| CharacterNode | 生成角色圣经、检查参考图一致性、创建表情或姿态需求 |
| SceneNode | 生成场景说明、检查镜头引用、补充光线和氛围 |
| PackageNode | 检查包完整性、重新导出、打开包目录 |
| VideoResultNode | review、创建修改任务、生成下一版建议 |

## 状态推进

| 状态 | 推进规则 |
| --- | --- |
| no_selection | Inspector 显示项目摘要和最近任务 |
| selected_clean | 展示当前对象详情，可切换 tab |
| selected_dirty | 标记未保存字段，切换对象前确认 |
| saving | 主操作进入等待态，表单仍显示用户输入 |
| save_failed | 字段保留 dirty，Bottom Bar 显示重试 |
| version_conflict | 阻断覆盖保存，进入冲突处理 |
| task_preview | 展示上下文、能力包、输出位置、风险 |
| task_submitted | 创建 PromptRun 并进入运行记录 |

GenerationPackage.status 在 Inspector 中只能显示和触发合法转换：`draft`、`ready`、`handed_off`、`result_received`、`stale`、`invalid`。

## 错误语义

| 错误 | 展示 |
| --- | --- |
| required_field_missing | 字段级提示，并阻断依赖任务 |
| save_failed | 保留输入，提供重试和查看详情 |
| version_conflict | 展示冲突字段，不允许静默覆盖 |
| task_context_invalid | 任务 tab 展示缺失对象和修复入口 |
| output_contract_missing | 阻断运行，提示缺少输出契约 |
| audit_load_failed | 审计 tab 显示不可用，不影响编辑 |

## 恢复与重试

- 保存失败后可重试当前对象保存，或导出未保存字段摘要。
- 冲突处理完成前，任务按钮保持禁用，避免使用过期上下文。
- 任务提交失败时保留预览内容，允许修复后重新提交。
- PromptRun 失败后可从运行记录 tab 发起重试，重试必须创建新记录。
- 审计加载失败时提供刷新，不阻断属性编辑。

## 验收标准

- 任意节点打开 Inspector 后都能访问六个固定 tab。
- 未保存编辑在切换节点、关闭面板、提交任务前都有明确处理。
- 版本冲突不会造成静默覆盖。
- 任务运行前可预览节点、资产、输出位置、输出契约和阻断风险。
- PromptRun 通过运行记录查看和重试，不被建模为图端点。
