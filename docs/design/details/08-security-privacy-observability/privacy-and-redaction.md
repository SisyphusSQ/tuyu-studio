# 隐私与脱敏

## 目标与边界

定义本地隐私默认值、凭据排除、禁止静默上传、docs/test 脱敏和问题报告导出脱敏。本文不定义具体密钥存储产品。

## 输入 / 输出

| 输入 | 输出 |
| --- | --- |
| 剧本、备注、参考图、结果文件 | 默认保存在项目目录或受控资产区 |
| 外部能力请求 | 用户确认、用途说明和运行记录 |
| 凭据或会话材料 | 排除项目目录、manifest、日志和报告 |
| docs/test 验证摘要 | 脱敏后的提交版测试真相 |
| 问题报告导出 | 可分享的脱敏包 |

## 核心对象或规则

本地隐私默认：

- 项目数据默认只保存在 `{studio_root}/projects/{project_id}`。
- 剧本正文、角色设定、参考图、创作备注默认不上传。
- 任务需要外部能力时，必须在任务预览展示数据范围和用户确认。
- 运行记录可以保存本地对象引用，但导出报告时必须脱敏。

凭据排除：

- 凭据、会话密钥、账号私密信息不得写入项目目录。
- manifest、GenerationPackage、PromptRun、audit、docs/test 都不得包含凭据。
- 配置文件只允许保存非敏感偏好和 profile 标识。
- 错误 JSON 记录前要过滤请求头、环境变量和授权字段。

无静默上传：

- 任何外部传输都必须由用户触发或由已确认任务触发。
- 任务预览必须展示将使用的节点、资产、输出契约和外部能力范围。
- 用户取消确认后，不创建 PromptRun，也不保留待发送材料。

docs/test 脱敏：

- 提交版验证摘要可以记录步骤、结果、错误码和对象类型。
- 不写真实剧本全文、私有素材地址、机器私有路径、凭据、内部主机。
- 路径示例使用 `{studio_root}` 或项目相对路径。

报告导出脱敏：

- 默认导出对象 ID、状态、错误码、摘要和结构化健康结果。
- 原始用户素材、长正文、私有配置默认排除。
- 用户显式包含素材时，需要二次确认并在报告 manifest 记录。

## 状态推进

| 状态 | 推进规则 |
| --- | --- |
| local_only | 默认状态，数据只在项目内 |
| external_preview | 展示外部能力请求范围 |
| external_confirmed | 用户确认后才提交任务 |
| report_preparing | 收集记录并应用脱敏规则 |
| report_ready | 生成可分享报告和脱敏清单 |
| report_blocked | 检测到不可脱敏敏感内容，阻断导出 |

## 错误语义

| 错误 | 语义 |
| --- | --- |
| credential_detected | 检测到凭据或会话材料，拒绝写入 |
| silent_upload_blocked | 外部传输缺少用户确认 |
| redaction_failed | 报告脱敏未完成，不能导出 |
| sensitive_path_detected | 检测到机器私有路径 |
| private_material_in_docs | 提交版文档包含私有素材 |

## 恢复与重试

- credential_detected 后移除敏感字段，再重新保存或导出。
- silent_upload_blocked 后回到任务预览，用户确认后重新提交。
- redaction_failed 后展示命中字段和建议替换，不生成报告。
- docs/test 命中敏感内容时，改写为脱敏摘要后重新检查。
- 用户报告误判时，可以选择排除该文件而不是放宽全局规则。

## 验收标准

- 新建项目默认不上传任何剧本、参考图或结果文件。
- 凭据不会进入项目目录、交接包、运行记录、审计或报告。
- 外部能力请求必须经过任务预览和用户确认。
- docs/test 只包含脱敏验证摘要，不包含私有素材或机器私有路径。
- 问题报告导出前执行脱敏检查，并产出脱敏清单。
