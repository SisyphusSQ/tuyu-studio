# 用户工作流

## 目标与边界

本文定义从 Project Canvas 创作到生成结果评审的主路径。工作流强调可中断、可恢复、可追溯，每一步都应产生明确项目状态，而不是只停留在临时界面状态。Package Export 是 handoff/fallback，不是第一屏主路径。

## 工作流：人类画布创作

| 项 | 内容 |
| --- | --- |
| 触发 | 用户打开本地 Project，进入 Project Canvas |
| 快乐路径 | 插入 Blueprint；导入剧本、角色、场景、参考图；创建或确认节点；连线；发起节点运行；结果回流为 Asset/Take；Inspector 中评审 |
| 中断点 | Blueprint 已插入但输入未补齐；节点运行等待用户确认；结果已回流但未 review |
| 失败路径 | 缺输入、provider 不支持、外发未确认、输出契约失败时节点进入 recoverable error |
| 验收标准 | 用户能在画布上看到节点、边、运行状态、结果、Review 和审计来源 |

## 工作流：Agent 通过 Skill/CLI 操作画布

| 项 | 内容 |
| --- | --- |
| 触发 | 外部 Agent 读取图屿 Skill，并调用 tuyu-studio CLI / MCP 风格命令 |
| 快乐路径 | Agent 打开项目；通过 Studio Command 创建节点、移动节点、连线、插入 Blueprint、发起 run、写回结果；UI 实时显示这些操作 |
| 中断点 | Agent 命令等待权限确认；run 等待用户补充；结果未绑定 |
| 失败路径 | 命令非法、路径越界、外发未授权、输出不符合契约时写入 Agent-visible error event |
| 验收标准 | Agent 操作不能直接写文件；所有操作可见、可审计、可被人接管 |

## 工作流：人机混合协作

| 项 | 内容 |
| --- | --- |
| 触发 | 用户框选画布节点或选择 Blueprint，要求 Agent 继续生成或整理 |
| 快乐路径 | Agent 读取选中上下文；创建候选节点和连线；用户在 Inspector 中确认、修改、运行或废弃 |
| 中断点 | Agent 输出候选但用户未接受；用户接管后产生新的人工修改 |
| 失败路径 | Agent 误判上下文时保留候选，不覆盖已锁定对象 |
| 验收标准 | 人和 Agent 的修改共享同一 Project Canvas version、Run/Event/Audit |

## 工作流一：新项目到第一个可运行 Shot

| 项 | 内容 |
| --- | --- |
| 触发 | 用户创建 Project，并选择项目类型、画幅、语言和默认 ProviderProfile |
| 快乐路径 | 创建本地目录；写入 `project.tuyu.json` 单一项目清单；进入 Project Canvas；录入项目原则；导入或编写剧本片段；创建 Scene、Character、Shot；连接 Shot 与上下文；确认 Prompt；发起节点运行或进入 handoff |
| 中断点 | 项目创建后未录入剧本；Shot 尚未补齐上下文；Prompt 已生成但未确认运行方式 |
| 失败路径 | 目录不可写时拒绝创建；必填上下文缺失时 Shot 不能进入 `context_ready`；输出契约失败时不写入正式 PromptObject |
| 验收标准 | 第一个 Shot 节点在画布中有上下文、Prompt、运行状态和审计事件；重新打开项目后画布状态和 Shot 引用一致 |

## 工作流二：角色 / 场景资产导入到连续性锁定 Shot

| 项 | 内容 |
| --- | --- |
| 触发 | 用户把参考图或说明导入 Character、Scene 或 Prop |
| 快乐路径 | 资产复制到项目内或记录受控引用；生成 digest；创建 asset metadata；绑定到领域对象；用户标记关键外观、场景规则或禁改项；相关 Shot 引用该对象并进入连续性检查 |
| 中断点 | 资产复制完成但尚未绑定；绑定完成但连续性字段未确认；连续性变更后关联 Shot 尚未重新确认 |
| 失败路径 | 文件不可读时导入失败；digest 计算失败时资产不可用于 Package；外部引用丢失时相关 Shot 显示缺失资产 |
| 验收标准 | Shot 可展示使用的角色 / 场景 / 道具规则和引用图；连续性规则变更后该 Shot 被标记为 `context_dirty`，重新确认前不能导出新 Package |

## 工作流三：PromptRun 预览到结构化输出

| 项 | 内容 |
| --- | --- |
| 触发 | 用户或 Agent 在 Shot、Prompt、Frame 或 Package 节点上请求生成或优化提示词 |
| 快乐路径 | 解析选中节点上下文；编译指令栈；展示来源、优先级、输出契约和预计输入；用户确认运行；记录 PromptRun；生成结构化输出；写入 PromptObject 或 Package 草稿 |
| 中断点 | 预览后未确认；运行中等待用户补充；输出完成但用户未接受写回 |
| 失败路径 | 必需上下文缺失时不进入运行；上下文过大时要求裁剪或摘要；输出不符合契约时标记 failed 并保留原始输出 |
| 验收标准 | 每次运行都有输入摘要、context digest、输出契约、状态、错误语义和可重试性；用户能在写回前看到结构化结果 |

## 工作流四：交接包导出到手动外部生成

| 项 | 内容 |
| --- | --- |
| 触发 | 用户对 `prompt_ready` 的 Shot 或一组 Shot 执行导出 |
| 快乐路径 | 校验 Shot 状态、资产存在性和路径相对性；创建 Package 版本目录；写 manifest、提示词、剧本片段、连续性说明、参考资产和上传清单；用户在外部工具中手动生成 |
| 中断点 | 健康检查有 warning 等待确认；Package 已导出但用户尚未标记提交；提交后等待结果回收 |
| 失败路径 | blocking 检查失败时拒绝导出；asset digest 不匹配时阻断；Package 写入失败时保留上一版 Package |
| 验收标准 | Package 不包含绝对路径和敏感本机痕迹；复制 Package 目录后 manifest 可独立检查；用户可把 Shot 标记为 `submitted` 并写入审计 |

## 工作流五：结果导入到评审与修订

| 项 | 内容 |
| --- | --- |
| 触发 | 用户拖入或选择外部生成的视频、图片或中间文件 |
| 快乐路径 | 计算 digest；选择或自动匹配 Package / Shot；创建 Take；生成缩略图和基础 metadata；进入 Review Status；用户评审为通过、需修改或废弃；需修改时创建修订说明并回到上下文确认 |
| 中断点 | 结果已入库但未绑定；绑定后未评审；评审为需修改但尚未重新生成 Prompt 或 Package |
| 失败路径 | 文件不可读时拒绝导入；无法匹配时进入未绑定结果区；digest 冲突时提示复用或保留新版本 |
| 验收标准 | 从 Take 可追溯到 Result 文件、Package、Shot、PromptRun 和关键上下文；评审结论不会覆盖历史 Take；修订会保留原因和目标差异 |

## 通用错误语义

| 错误 | 处理 |
| --- | --- |
| 缺少必填上下文 | 阻断状态推进，列出缺失对象 |
| 资产缺失 | 允许继续编辑，不允许正式导出受影响 Package |
| 运行失败 | 保留 PromptRun 和原始错误，允许按同一输入重试 |
| 写入失败 | 保留上一版有效文件，提示用户重试或另存 |
| 用户取消 | 记录取消事件，清理可安全删除的临时文件 |

## 验收标准

- 五条主路径均可从触发动作推进到可见状态，并能在中断后恢复。
- 每条路径都有明确 failure path，不把失败吞成普通完成。
- 所有正式产物都能写入 audit，并能从结果反向追溯到源 Shot 和上下文。
- 用户手动外部生成是显式步骤，系统不静默提交外部任务。
